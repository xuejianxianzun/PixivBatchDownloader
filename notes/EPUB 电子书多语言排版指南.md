# EPUB 电子书多语言排版指南：垂直排版（竖排/直排）术语与行业现状

在开发多语言 EPUB 阅读器或制作电子书时，文字的排列方向（横排 vs 竖排）是核心的本地化与排版问题。本文档总结了主流语言中关于“垂直排版”的专业术语、CSS 规范以及不同地区的使用现状。

---

## 一、 垂直排版的专业术语与本地化翻译

在软件界面的本地化（I18N）和专业讨论中，不同语言对“从上到下排版”的称呼有所不同。建议在阅读器 UI 或开发文档中采用以下标准词汇：

| 语言环境 | 本地化/专业术语 | 适用场景与备注 |
| :--- | :--- | :--- |
| **简体中文 (zh-CN)** | 竖排 / 竖排文字 | 现代大陆日常用语及阅读软件UI标准词。学术或历史语境下有时称“纵排”。 |
| **繁体中文 (zh-TW)** | 直排 / 直式排版 | 港台出版界绝对的行业标准词。UI 中通常显示为“直排/橫排”。 |
| **日语 (ja)** | 縦書き (Tategaki) | 电子书UI及普通读者最常用的标准词。（排版业界底层有时称“縦組み”） |
| **英语 (en)** | Vertical Text | UI 界面最常见用法。在 CSS 和 W3C 规范中称为 **Vertical Writing Mode**。 |
| **韩语 (ko)** | 세로쓰기 (Sero-sseugi)| 韩语中原生的标准专业名词，UI 翻译首选。 |
| **俄语 (ru)** | Вертикальный текст | 俄语无原生竖排传统，此为直译的“垂直文本”，适用于 UI 翻译。 |

---

## 二、 核心 CSS 技术规范 (Writing Mode)

无论使用哪种语言沟通，在 EPUB 的底层代码（HTML/CSS）中，控制排版方向的最准确“国际通用语”是 CSS 的 `writing-mode` 属性。

### 1. 中日韩传统竖排 (从右向左)
适用于**日文**、**繁体中文**。文字从上到下，换行时**从右向左 (Right-to-Left)** 推进。
```css
.vertical-text {
  writing-mode: vertical-rl;
}
```

### 2. 传统蒙古文竖排 (从左向右)
世界上唯一在现代大众小说中强制使用此排版的文字。文字从上到下，换行时**从左向右 (Left-to-Right)** 推进。
```css
.mongolian-text {
  writing-mode: vertical-lr;
}
```

## 三、 各语言与地区的小说排版现状

对于 EPUB 开发者而言，在处理不同语言（Locale）的默认排版时，需遵循当地的行业习惯：

### 1. 强烈依赖竖排 (Vertical-RL 优先)
* **日语 (ja)**：极度保留竖排传统。绝大部分小说、散文、轻小说均默认且必须提供竖排支持。
* **繁体中文 - 台湾 (zh-TW)**：竖排（直排）被视为文学出版的“绝对正统”。小说类内容强烈建议默认采用竖排，否则会被读者视为不够专业。

### 2. 竖排与横排并存 (视情况而定)
* **繁体中文 - 港澳 (zh-HK / zh-MO)**：由于中英混排的日常需求和教育系统的影响，横排在港澳极为普及。现代港产小说默认使用横排（Horizontal LTR）是完全符合当地习惯的。经典文学复刻或版权书才会保留直排。

### 3. 几乎全面采用横排 (Horizontal-LTR 优先)
* **简体中文 (zh-CN)**：小说等大众出版物几乎全面采用横排。竖排仅见于古籍整理或特定的复古设计。
* **韩语 (ko)**：历史上有过竖排，但现代韩国出版界（包括传统小说和网文）已彻底转向横排。处理韩文 EPUB 时，默认横排即可，通常不需要配置 `vertical-rl`。
* **其他全球语言 (英语、俄语等)**：除上述提及的语种外，世界上 99% 的主流语言小说均使用纯粹的横排。

### 4. 特殊必选项 (强制 Vertical-LR)
* **传统蒙古文 (mn)**：由于没有任何原生的横排形态，强行横排会导致文字横躺，阅读体验极差。开发蒙古文阅读器时，**必须**依赖且默认开启 `writing-mode: vertical-lr`。

## 四、 给阅读器开发者的 UX 建议

1. **多语言一键切换功能**：对于繁体中文（无论 TW 还是 HK）甚至简体中文，阅读器内部最好提供一个全局的 **“直排/横排 切换按钮”**。这能最大程度兼容不同地区读者的个人偏好。
2. **标点符号适配**：在切换为直排时，需注意中日文标点符号的位置和字形转换（例如引号 `“”` 需变为 `「」`，破折号需要垂直显示）。这通常依赖系统字体的支持以及 CSS 中 `text-orientation: upright;` 等属性的配合。
