# 作品详情页底部的推荐作品和相关作品

在作品页面里，例如：
https://www.pixiv.net/artworks/150004057

其底部显示的作品列表可能是下面 2 种情况中的一种：
1. 推荐作品
2. 相关作品

## 推荐作品

对于**新发表不久**的作品，可能是因为 pixiv 还没来得及为其生成相关作品（相似作品）的数据，因此底部会显示推荐作品列表。

推荐作品的特点是：
- 固定只有 18 个作品
- 在不同作品页面里，推荐作品的内容是高度相似的。因为它是为当前登录用户推荐的个性化作品。它其实就是 [发现页面](https://www.pixiv.net/discovery) 里最前面的那些作品。

推荐作品的 API 格式是：

https://www.pixiv.net/ajax/{type}/discovery?mode={mode}&max={max}&lang=zh

参数：

- `type`：可能是 `illust`（插画、漫画）、`novel`（小说）。
- `mode`：根据这个作品的年龄限制变化：
  - 如果这个作品是全年龄的，那么 `mode` 固定为 `safe`，即只获取全年龄的推荐作品
  - 如果这个作品是 R-18 或 R-18G 的，那么 `mode` 固定为 `all`，会获取全年龄和 R18 的混合作品
  - 备注：虽然 `mode` 可以使用 `r18`（只获取 R18 作品），但在作品页面里，pixiv 的官方代码不会使用 `r18`。
- `max`：固定为 18。这也是最大值，超过 18 会产生 400 错误（"不正确的请求"）。注意：当 `type`是 `illust` 时，返回的作品数量确实是 `max` 参数的数量；但是当 `type`是 `novel` 时返回的小说数量很多：当 `max` 为  18，返回的数量是 120 个。

示例：

- https://www.pixiv.net/ajax/illust/discovery?mode=safe&max=18&lang=zh
- https://www.pixiv.net/ajax/illust/discovery?mode=r18&max=18&lang=zh
- https://www.pixiv.net/ajax/novel/discovery?mode=all&max=18&lang=zh
- https://www.pixiv.net/ajax/novel/discovery?mode=r18&max=18&lang=zh

数据类型：
- 当 `type`是 `illust` 时，数据类型是 `BottomRecommendedWorksOnArtworkPage`
- 当 `type`是 `novel` 时，数据类型是 `BottomRecommendedWorksOnNovelPage`

## 相关作品

如果这个作品发表过了一段时间（6 小时左右），pixiv 会为它生成相关作品数据，因此底部会显示相关作品列表。

相关作品的 API 是：

https://www.pixiv.net/ajax/illust/${id}/recommend/init?limit=18

`src/ts/crawlArtworkPage/InitArtworkPage.ts` 模块的 `getRelatedList` 方法使用了这个 API 来抓取相关作品。

这个 API 返回的数据类型是 `RecommendData`。

新发表作品没有相关作品数据，此时 `RecommendData` 里的 3 个数组都是空数组。
