本文档里出现的所有需要显示在界面上给用户看的文字，都需要在 `src/ts/langText.ts` 里添加其 i18n 文本。如果有些文本已存在，可以复用。

> 常用标签的数量改为可设置）。界面的最终状态以「执行方案」一节为准。

## 添加一个开关

为编号 88 的“下载器收藏作品时的行为”添加一个子选项，名称是“手动收藏作品时，显示一个操作面板，让我设置收藏参数”。该子选项是一个开关（美化的复选框），默认未启用。
它后面有一个帮助按钮，点击后显示的内容是：
```html
以下情况可以显示操作面板：<br>
- 点击下载器的收藏按钮(✩)，而不是 Pixiv 自己的心形收藏按钮；<br>
- 在预览作品时、使用图片查看器时，使用快捷键（B）收藏这个作品。<br>
<br>
这些操作都只会收藏 1 个作品，此时下载器可以显示一个操作面板，让用户设置是否公开收藏、使用哪些标签（可以自行输入标签），然后再收藏。<br>
<br>
备注：<br>
- 只有当你经常需要手动设置收藏标签，或者经常使用不同的公开选项时，才需要启用这个功能。<br>
- 操作面板只会在你手动收藏 1 个作品时显示。在批量收藏作品时（例如“下载之后自动收藏作品”）不会显示，因为在批量收藏时，下载器可能需要添加几十、几百个收藏，不适合让用户逐一操作。<br>
```

## 作用

当用户启用这个设置之后，在下面这些模块里调用 `bookmark.add` 方法之前，都会先显示一个操作面板，等用户在操作面板上点击了“收藏”按钮之后，才会真的执行收藏（调用 `bookmark.add`）。用户可以取消操作面板，此时会取消执行，不进行收藏。

这些模块有：
- src/ts/AddBookmarkFromWorkThumb.ts
- src/ts/ImageViewer.ts
- src/ts/crawlArtworkPage/SearchResultPreview.ts
- src/ts/pageFunciton/QuickBookmark.ts

如前面的帮助所说，只有当用户使用下载器的收藏功能，并且是手动收藏 1 个作品时才会触发；其他情况不会触发。

## 面板的内容

需要新增一个模块来实现面板操作的功能。

面板在 PC 端的宽度是 50vw，最大宽度 700px。通常默认宽度就会显示为 700px。
在移动端的宽度是 84vw，最大宽度也是 700px。

这个面板样式四周使用圆角，样式优美，风格简洁，内容偏紧凑。

需要能在浅色、深色模式里有对应的样式。
有个特殊情况需要处理：在图片查看器里点击收藏按钮时，由于图片查看器总是暗色的（并且会覆盖整个网页），此时面板也应该使用暗色。为此我想这样处理：
1. 在 States 模块里添加一个状态标记，表示图片查看器当前是否是显示的。
2. 面板优先判断图片查看器是否显示，如果是的话就总是使用暗色主题；否则默认自行获取网页的颜色主题（src/ts/Theme.ts 的 getThemeFromHtml 方法）并使用对应的主题。

面板里有以下几个主要区域。

### 作品的简要信息

左右排列，左侧是作品封面图片；右侧是上下排列，显示作品标题、作品本身的标签列表。

这需要用到作品数据，从缓存模块 src/ts/store/CacheWorkData.ts 的 getWorkDataAsync 方法获取作品数据，然后提取。

如何显示封面图片：
- 如果是图像作品(ArtworkData)，使用 `body.urls.small` 作为封面图的网址。PS：如果作品里有多张图片，也只会显示这一个缩略图（也就是第一张的缩略图）。
- 如果是小说作品（NovelData），使用 `body.coverUrl` 作为封面图的网址。
封面图片的宽度：整个面板宽度的 1/3；最大宽度是 180px。高度最大 180px。显示时保持原比例。

作品标题字号稍微加大一些，加粗显示。

标签列表区域的内容示意：

```
标签列表：
{标签列表}
（提示文字，字号减小，颜色较浅）点击一个标签即可把它添加到收藏时使用的标签里。
```

其中，标签列表是同时获取原标签和翻译后的标签列表：

```ts
const tagsWithTransl = Tools.extractTags(data, 'both', 'check').map(
  (str) => '#' + str
)
```

每个标签都渲染为一个可点击的元素，文字是蓝色的，看起来像超链接。

另外，还要保存一份 `Tools.extractTags(data, 'origin')` 即原标签列表备用。

备注：需要修改 `extractTags` 方法。目前当第二个选项为 both 时，翻译后的标签是附加到原标签后面的，但不是一个原标签后面跟着一个翻译标签的一一对应的关系。需要改为对应关系。
可以把 tagsTransl 改为稀疏数组，在 `tags.push(tagData.tag)`（添加了原标签）之后，如果没有或者不需要添加它的 tagsTransl，则把 tagsTransl 的这一个位置留空。
在最后返回时，`return Array.from(new Set(tagsTransl))` 里去除空值；`return Array.from(new Set(tags.concat(tagsTransl)))` 里改为添加一个原标签；添加它对应索引的标签（如果有就添加，没有就不添加），这样一一对应的关系。

添加到

它的内容区域里有两个选项，显示在一行里即可。选项分别是：

### 设置收藏时使用的标签列表

#### 标题

该区域的标题是：
收藏时使用的标签

#### 选项列表

然后是 3 个单选的选项：
1. 使用作品的标签
2. 不使用标签
3. 自定义标签。它下面一行有输入区域，靠右缩进一些显示。
需要在 Settings 里添加一个设置项，保存这个单选框的值。默认值是第一个选项，即默认使用作品的标签
当用户修改了选中的选项时，同时修改 Settings 里的这个设置项。
每次打开新的操作面板时，使用这个设置项来设置该选项的默认值。

输入区域：
左侧是个标签输入框，提示文字是 `请输入标签`（支持 Enter 触发“添加”动作；需要排除组词时的 Enter）；输入框右侧是“添加”按钮。
输入框底部有提示小字（样式和简要信息里的提示文字相同），内容是：
```html
你可以输入一个或多个标签，并添加到下方的收藏标签列表里。<br>
标签前面不需要添加<span class="blue">#</span>。<br>
多个标签之间使用英语逗号 <span class="blue">,</span> 分隔。
```

#### 收藏标签列表

接下来是一个收藏标签列表区域，标题是`添加这些收藏标签：`。
它显示的是要提交给 `bookmark.add` 的标签列表。
在模块内部有一个对应的变量 `bookmarkTags` 保存这个列表；这个变量变化时会自动更新这个列表的渲染。`bookmarkTags` 有去重处理。
渲染的样式和摘要信息里的标签列表相同。
它的底部有一行提示小字（样式和简要信息里的提示文字相同），内容是 `点击一个标签可以移除它。`

`bookmarkTags` 的值会这样变化：
- 当用户选择“使用作品的标签”时，把 `bookmarkTags` 的值设置为作品的原标签列表（不是原标签+翻译后标签的混合列表）
- 当用户选择“不使用标签”时，把 `bookmarkTags` 设为空数组
- 当用户选择“自定义标签”时，**保留** `bookmarkTags` 当前的值（这样可以在现有的标签上修改，不需要从空白开始）
- 当用户在输入区域里点击“添加”按钮时，执行动作：
  - 如果输入是空值则不处理
  - 使用 `,` 把输入分割为数组
  - 遍历每一项，移除开头的一个 `#`（只移除第一个）。如果移除后还有值，则添加到 `bookmarkTags` 里
- 当用户点击收藏标签列表里某个标签时，把它从 `bookmarkTags` 里移除

#### 常用的标签

需要在设置里添加一个数组，每一项是一个对象，保存一个标签及其使用次数。

```ts
[
  {
    tag: string
    count: number
  }
]
```

只有通过此面板发送收藏请求时（可以在执行 `bookmark.add` 之前处理），把使用的收藏标签添加到这个数组里；这个数组本身没有长度限制。如果之前已存在该标签，则使其次数 + 1；如果之前没有该标签，则 count 的默认值是 1。数组变化后通过 `setSetting` 方法提交变更。

在打开操作面板时，读取此数组，并按 count 降序排序，取出排在前面的标签（最多 30 个），按照顺序渲染。

点击其中任意一个标签，就会把它添加到 `bookmarkTags` 里。

#### 提交按钮

底部的一个大按钮，文字是`添加收藏`。

字体较大，占据较大宽度（但不占满），宽度主要由 padding 撑开。水平居中显示。

按钮右侧有小的提示文字：`快捷键 Ctrl + Enter`。

点击这个按钮之后，执行收藏动作，并更新设置里的“常用的标签”数组。

当这个面板显示时并且处于焦点时，按 Ctrl + Enter 触发同样的功能。

## 未采用的设计

这两个 API 可以获取当前用户所有的收藏标签（从所有已收藏的作品里获取的）：
- https://www.pixiv.net/ajax/user/9460149/illusts/bookmark/tags?lang=zh
- https://www.pixiv.net/ajax/user/9460149/novels/bookmark/tags?lang=zh

由于这些标签数量可能很多（几千个很常见），因此不适合在这个操作面板里展示。原因：
- 数量太多，不适合完全显示出来，基本上只适合显示前面一部分。虽然强行显示的话也能全部显示出来，但这会很难使用
- 可能需要做搜索功能，太麻烦
- 当用户添加了新的作品之后，这个列表里可能会有新增的标签。如果要临维护数据一致性的话，也是个麻烦

因此我没有使用这个设计。使用“常用的标签”可以部分代替此功能。虽然“常用的标签”默认是空的，但用户添加收藏的次数多起来之后，就会越来越好用。所以没太大必要把所有标签都显示出来。

## 执行方案

日期：2026-10-20。在初次实现之后，我又进行了大量的调整和优化，现在已经定型。

本节按**当前代码**重新整理，不记录逐步修改的过程（过程见 git 历史）。

### 1 设置项（`src/ts/setting/Settings.ts`）

| 设置 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `showBookmarkPanel` | `boolean` | `false` | 手动收藏 1 个作品时是否显示收藏面板 |
| `bookmarkPanelRestrict` | `'public' \| 'private'` | `'public'` | 面板里“添加到”的选择，记住上一次的选择 |
| `bookmarkPanelTagMode` | `'origin' \| 'transl' \| 'none' \| 'custom'` | `'origin'` | 面板里“标签策略”的选择 |
| `bookmarkPanelCommonTags` | `BookmarkPanelCommonTag[]` | `[]` | “常用的标签”，每项 `{ tag: string; count: number }`，**不限长度** |
| `bookmarkPanelCommonTagsMax` | `number` | `30` | 面板里最多显示多少个“常用的标签”，取值 0 - 100（0 = 不显示该区域） |

- `BookmarkPanelCommonTag` 接口也写在 `Settings.ts` 里（与 `BlockTagsForSpecificUserItem` 同样的写法）。
- 设置面板的表单里只有两个元素需要接线：
  - `showBookmarkPanel` → `FormType.d.ts`（`HTMLInputElement`）+ `FormSettings.inputFileds.checkbox`
  - `bookmarkPanelCommonTagsMax` → `FormType.d.ts`（`HTMLInputElement`）+ `FormSettings.inputFileds.text`
  🔴 **类型数组必须放对**：文本输入框放进 `checkbox` 时，`saveCheckBox` 会读 `el.checked`（`undefined`），
  于是每次点击输入框都会弹「设置的值不正确，需要是数字」。`setSetting` 会把输入框的字符串 `parseInt` 成 number。
- `bookmarkPanelRestrict` / `bookmarkPanelTagMode` / `bookmarkPanelCommonTags` 由面板自己 `setSetting` 保存，
  不在设置表单里，不需要 FormType / FormSettings 接线。
- 旧版本的配置文件里没有这些设置，`assignSettings` 只循环导入数据里存在的 key，所以它们会保持默认值，不需要迁移。

### 2 设置面板里的设置项

**设置项 88「下载器收藏作品时的默认行为 (✩)」**：

- 是否公开（`restrict`）
- 是否添加标签（`widthTag`），3 个选项：`origin`（添加作品的原始标签）/ `transl`（添加翻译后的标签）/ `none`（不添加）。
  - 派生的 `widthTagBoolean = widthTag !== 'none'`。
  - ⚠️ 这个值改过两代：最早 `'1' / '-1'`，之后 `'yes' / 'no'`，现在是这三个。转换在
    `ConvertOldSettings.stringSettingsMap.widthTag`，一次映射即可（`1`→origin、`-1`→none、`yes`→origin、`no`→none）；
    旧值经 `assignSettings → setSetting → convertString` 迁移，本地存储和导入的配置文件都会走这条路径。
- 收藏时用什么标签由 `Bookmark.getTagsBySetting()` 决定（见第 6 节）。

**设置项 117「收藏面板」**（紧跟在 88 后面）：

- 名称 `_收藏面板`（文本是 `收藏<span class="key">面板</span>`），右侧帮助按钮 `data-title="_收藏面板"`、`data-msg="_收藏面板的帮助"`。
- 第一行：开关 `showBookmarkPanel`（`need_beautify checkbox_switch`）。
- 第二行：`_显示多少个常用标签` + 输入框（`setinput_style blue w50`，默认 30）+ `<span class="gray">0 - 100</span>`。
- 第三行：「清空常用的标签」按钮（`class="textButton fireEvent borderButton"`，`data-event="clearBookmarkPanelCommonTags"`）。
  - `.fireEvent` 按钮由 `SettingsPanelBootstrap.bindFunctionButtons()` 统一处理（点击时 `EVT.fire(btn.dataset.event)`），
    所以只需要在 `EVT.list` 和 `EVT.fire` 的联合类型里加事件名。
  - 处理逻辑在 `BookmarkPanel`（构造函数里监听）：`window.confirm(_确认清空常用的标签)` →
    `setSetting('bookmarkPanelCommonTags', [])` → `toast.success(_已清空常用的标签)`。
    放在这里是因为 `bookmarkPanelCommonTags` 的记录逻辑本来就在这个模块，且内容脚本启动时必然加载它，不用额外接线。

**编号与分类**：

- 🔴 `data-no` 必须唯一、且是整数：置顶（`pinnedOptionsV2`）、隐藏设置、wiki 链接都按 `parseInt(data-no)` 存取，
  写成 `88.1` 会被当成 88，与原有设置项冲突。新设置项取当前最大值 + 1（现在是 117）。
- 显示顺序**不看编号**，而看 `OptionConfigs.options` 数组的顺序（`SettingsPanelPlacement` 按数组顺序 append），
  所以把配置项插在 `no: 88` 后面，它就显示在 88 下方。
- 88 和 117 都在新增的二级分类 `enhance` → `bookmark`（`order: 3`、`icon: 'category-bookmark-line'`、`nameKey: '_分组_收藏'`）。
  新增二级分类时要补的接线：
  - `Settings.ts` 的 `expandedCards` 默认值里加上它的折叠状态（`enhance.bookmark: false`；只有首个二级分类才是 `true`）。
    漏了不报错（`getExpandedState` 把 `undefined` 当作折叠），但用户的展开/折叠状态不会被记住。
  - 图标：SVG 放在 `src/static/icons/`，跑 `npm run gen:icons` 重新生成 `src/static/lib/icon-sprite.js`，
    ⚠️ 再**手动同步到 `dist/lib/`**（开发时加载 dist，`npm run ts` 不复制 static）。
  - 分类名的 key 要有 6 语。
  - 导航、搜索、wiki 链接、提示卡片都从 `categorySchema` 自动生成，不需要额外接线（`tipCardKey` 是可选的）。

### 3 `Tools.extractTags` 的改动

- `tagsTransl` 改成稀疏数组，下标与 `tags` 一一对应；没有翻译、或者不需要翻译
  （`purpose` 为 `save` 且原标签是中文而翻译是纯英文）时，这个位置留空。
- 新增第 4 个参数 `interleave = false`：
  - 默认 `false`：`both` 返回「全部原标签 + 全部翻译标签」。⚠️ 这是文件名里 `{tags_translate}` 依赖的顺序，不能改。
  - 传 `true`：原标签后面紧跟它的翻译（成对展示）。目前只有收藏面板的作品标签列表传 `true`。
- `transl` 模式**保持旧行为**：没有翻译的标签回退为原标签。`SaveArtworkData` 用 `extractTags(data, 'transl', 'save')`
  做标签检查，去掉空值会漏掉这些标签。
- `both` 返回的集合与以前完全相同，只是相邻关系变了。

### 4 面板模块 `src/ts/BookmarkPanel.ts`

- 对外只有一个方法：`bookmarkPanel.show(id, type, workData?): Promise<BookmarkPanelOption | undefined>`。
  返回 `{ tags, restrict }` 表示用户确认；返回 `undefined` 表示取消（关闭按钮、点击遮罩层、按 Esc、切换页面）。
  `workData` 可以传入调用方已有的作品数据，避免重复请求；没传入时用 `cacheWorkData.getWorkDataAsync()`，
  获取失败时面板照常显示（只是没有作品的简要信息）。
- `bookmarkPanel.isOpen` 供其他模块判断。
  ⚠️ 语义是「面板存在」，**不是**「面板可见」：看大图时面板只是被加了 `.is-hidden`，`isOpen` 依然是 true，
  所以「面板隐藏时也要正常工作」的模块（如 `ShowOriginSizeImage`）不能用它。
- 板块顺序：作品卡片 → **添加到** → **使用的收藏标签**（`.noDivider`，去掉 `border-top`，与「添加到」连成一体）
  → **标签策略**（4 个单选）→ **手动添加标签**（独立的输入区，不再隶属于某个单选项）→ **常用的标签** → 提交按钮。
- 主题：优先判断 `states.imageViewerIsShow`（为真时总是暗色），否则用 `theme.getThemeFromHtml()`；
  给面板加 `theme-dark` / `theme-white`，**不使用** `theme.register()`（注册会跟随下载器的主题设置，并把元素永久留在 Theme 的列表里）。
- 宽度：PC 端 `50vw`、移动端 `84vw`，`max-width: 700px`。
- 面板是临时元素：直接用 `lang.transl()` 取文本（不用 `lang.register()`），也不随语言变化刷新。
- 转义：作品标题、标签列表用 `textContent` 渲染；写进 HTML 模板的标题、封面 URL、选项文字经过 `escapeHTML()`。

**「使用的收藏标签」**：

- 上限 `bookmarkTagsMax = 10`（pixiv 对一个作品的收藏标签数量限制）。
  ⚠️ 改这个值时要同步改 langText 里 `_标签数量` 和 `_收藏标签数量达到上限` 的文本。
- `addTags()`：达到上限后多出的标签**不添加**，并 `msgBox.warning(_收藏标签数量达到上限)` 提示先移除一些标签。
  `addTagsFromInput()` 只有真的添加了标签时才清空输入框（否则用户白打一遍）。
- `resetBookmarkTags()` 按标签策略取值：
  `origin` → `Tools.extractTags(data, 'origin')`；`transl` → `Tools.extractTags(data, 'transl', 'save')`；
  两者都会截断到 10 个；`custom` → **保留当前列表**（方便在现有标签上增删）；`none` → `[]`。
- 提示文字由代码拼成两行：`_点击标签可以移除它` + `<br>` + `_标签数量`（`标签数量：{}（最多 10 个）`）；
  达到 10 个时，在数量那一行的末尾追加 `<span class="maxTagsTip">_标签数量已达到最大值</span>`（只占同一行，不再单独占一行）；
  没有标签时整块隐藏。
- `renderBookmarkTags()` 末尾调用 `markAddedTags()`：在作品标签列表（去掉 `#` 再比较）和常用标签列表里，
  给已经添加的标签加 `.is-added` 标记。
  ⚠️ `.is-added` 的 CSS 要写在 `:hover` 规则**之前**，并且要给 `.is-added:hover` 单独写颜色，否则 hover 会把标记冲淡。

**「常用的标签」**：

- 只在通过面板发送收藏请求时记录（`recordCommonTags`），保存在 `bookmarkPanelCommonTags`（不限长度）。
- 打开面板时 `sortCommonTags(list, getCommonTagsMax())`：`getCommonTagsMax()` 读设置并裁剪到 0 - 100；
  数量为 0 或列表为空时隐藏这个区域。

**封面图可点击**：

- 图像作品 → `EVT.fire('callShowOriginSizeImage', illustId)`；移动端没有这个模块（`ShowOriginSizeImage` 构造时就 return），
  改为在新标签页打开 `body.urls.original`。
- 小说作品 → `window.open(body.coverUrl, '_blank')`（下载器里没有查看小说缩略图的模块）。

**查看大图时**：

- `ShowOriginSizeImage` 的 `show` setter 在关闭时（用 `wasShow` 判断，因为显示另一张图前也会先置 false）触发新增的事件 `hideOriginSizeImage`。
- 面板监听 `showOriginSizeImage` → `hiddenForImage = true` + 给面板加 `.is-hidden`；监听 `hideOriginSizeImage` →
  `setTimeout(..., 0)` 之后恢复面板并清掉标记。
  🔴 **必须延迟恢复**：按 Esc 关闭原图时，`ShowOriginSizeImage` 的**捕获阶段**监听先执行并触发 hide 事件，
  同一个 Esc 之后还会冒泡到面板的 keydown；立刻清标记会让面板被这次 Esc 一起关掉。
- 遮罩层**不隐藏**（原图层级比它高，也避免看大图时误点下面的页面）；`hiddenForImage` 时遮罩的点击处理直接 return。
- 如果原图没有成功显示（不会触发 `showOriginSizeImage`），面板就不会隐藏，不会出现“面板消失后回不来”。

**提交**：

- 按钮上的快捷键提示是 `_B或者CtrlEnter`（移动端 `.hotkey` 本来就不显示）。
- `Ctrl + Enter` 和 `B` 都能提交。`isSubmitByBKey()` 的排除条件：不是 `KeyB`、按下了 Ctrl/Shift/Alt/Meta、
  输入法正在组词（`isComposing || keyCode === 229`）、焦点在 `INPUT` / `TEXTAREA`；`hiddenForImage` 时整个处理器直接返回。
- 🔴 用 B 提交时要 `ev.stopPropagation()`：作品页面里 Pixiv 自己的收藏快捷键也是 B，
  只 `preventDefault()` 拦不住其他监听器。

### 6 接入调用方

4 个模块在调用 `bookmark.add` 之前先显示面板并等待用户确认，写法一致：

```ts
let tags = bookmark.getTagsBySetting(workData)
let restrict: boolean | undefined = undefined
let needAddTag: boolean | undefined = undefined

if (settings.showBookmarkPanel) {
  const option = await bookmarkPanel.show(id, type, workData)
  if (!option) {
    return // 用户取消了面板
  }
  tags = option.tags
  restrict = option.restrict
  needAddTag = true // 面板里的标签是用户明确选择的，覆盖“是否添加标签”设置
}

const status = await bookmark.add(id, type, tags, needAddTag, restrict)
```

- 它们分别是 `AddBookmarkFromWorkThumb`、`ImageViewer`、`SearchResultPreview`、`QuickBookmark`。
- `QuickBookmark` 里，面板确认之后才会点击 Pixiv 原本的收藏按钮（发送原生收藏请求），避免用户取消之后作品已经被 Pixiv 收藏。

**与「点击收藏按钮时下载作品」的配合**：

- `AddBookmarkFromWorkThumb.add()` / `ImageViewer.addBookmark()` / `QuickBookmark.addBookmark()` 都有
  `onConfirmed?: () => void` 回调，在「用户确认之后、发送收藏请求之前」调用；调用方在这里 `downloadOnClickBookmark.send()`。
  （不用方法的返回值，否则下载会排在收藏请求之后，请求重试时会被明显延后。）
- ⚠️ `QuickBookmark` 还有一条下载路径：确认之后 `pixivBMKBtn?.click()` 会被 `DownloadOnClickBookmark` 的监听捕获而触发下载；
  `sendDownload()` 只负责「找不到 Pixiv 收藏按钮」的情况，不要重复发送。
- 不受影响、也不需要改的路径（它们不显示面板）：点击 Pixiv 自己的心形收藏按钮。

**添加收藏时使用的标签**：

- 🔴 统一走 `Bookmark.getTagsBySetting(data)`：`none` → `[]`，`transl` → `Tools.extractTags(data, 'transl', 'save')`，
  `origin` → `Tools.extractTags(data)`。
- 改用它的调用点：`Bookmark.add` 的内部回退、`AddBookmarkFromWorkThumb`、`ImageViewer`、`QuickBookmark`、`BookmarkAllWorks`。
- 基于抓取结果的两处（`BookmarkAfterDL`、`SearchResultPreview`）在 `widthTag === 'transl'` 时使用结果里的
  `tagsTranslOnly`（它本来就是 `extractTags(data, 'transl', 'save')` 存下来的）。

**快捷键冲突**：

- `ImageViewer`、`PreviewWork` 的快捷键监听里加 `bookmarkPanel.isOpen` 判断：面板打开时不再响应它们的一级快捷键，
  否则按 B 会再次弹出面板、按 Esc 会连带关闭图片查看器/预览。
- `ImageViewer` 里还要在 `await bookmarkPanel.show(...)` 前后把 `this.myViewer.options.keyboard` 置为 false（`finally` 还原）：
  viewerjs 自己在 `document` 上绑了 keydown，不关掉的话 Esc 会连带关掉查看器。
- 🔴 `ShowOriginSizeImage` **不能**加 `isOpen` 判断（见第 4 节）；它在启用收藏面板时按 B 会先 `this.show = false`
  关闭原图区域（原图层级 100001 会挡住面板 3001）。
