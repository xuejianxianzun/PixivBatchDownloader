# 把 Markdown 文本转换为 HTML 格式

我平时习惯使用 Markdown 格式编写文本。当我需要把一些文本显示在网页上时，就需要转换成 html 格式。

## 转换规则

对需要转换的 Markdown 文本进行以下处理：
- 执行**一次**全局替换，把连续的两个换行替换成 1 个换行，使排版更加紧凑。注意：有些文本之间可能有 3 个换行，这是故意的。它们在替换一次之后还剩下 2 个换行，不需要再次替换。
- 在每个换行处添加一个 `<br>` 标签。
- 保持原本的换行格式，不要把所有文本压缩到一行。如果原始文本是多行的，那么转换后依然保持为多行文本。这样有利于人类阅读源代码。
- 对于标题行，我通常会使用二级或三级标题的符号，即 `##` 和 `### `，把这些标题都改为使用 strong 标签，例如：`<strong>原标题内容</strong>`。
- 对于每个反引号对（用于高亮显示关键词），都改为 `<span class="blue">原内容</span>` 的格式。
- 对于 Markdown 格式的链接 `[]()`，把它们转换成 HTML 的 `A` 标签，并且设置 `target="_blank"` 属性。

如果我没有说明要如何处理转换结果，那么就在对话里直接输出，把转换结果包裹到一个 html 代码块里。
有时我可能会让你把输出结果填充到某个地方，或者进行其他处理，则另当别论。
