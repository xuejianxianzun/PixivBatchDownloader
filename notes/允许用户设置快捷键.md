# 允许用户设置快捷键

## 概述

现在下载器有很多快捷键，但都是内置的。有些用户想修改快捷键（特别是当一些快捷键与其他扩展有冲突时），所以需要添加自定义快捷键的功能。

下载器的快捷键分为一级快捷键和二级快捷键。一级快捷键是在 pixiv 的网页里始终生效的，可以直接使用（不过有些只在特定页面里生效）；二级快捷键则是某些功能的子快捷键。例如：
- Alt + X 是一级快捷键，它用来切换显示下载器的设置面板，在任何时候都可以使用（只要在 pixiv 的页面里）
- 在预览作品时，可以使用快捷键 B 来收藏作品。这个快捷键仅能在预览作品界面显示时工作。如果预览界面未显示，它就不会生效（不过此时可能有其他模块会使用这个快捷键）。

## 需求

- 浏览器扩展有让用户自定义快捷键的功能，可以使用这个机制。我不知道 Chrome 和 Firefox 浏览器在这方面有没有差异，希望能兼容两种浏览器。
- 只需要让用户设置一级快捷键，不需要让用户设置二级快捷键。
- 如果用户修改了这些快捷键，那么下载器在绑定时需要使用用户设置的快捷键。
- 下载器会在一些按钮上显示快捷键提示，默认显示的是内置的快捷键。如果用户修改了快捷键，就需要能显示用户设置的快捷键。这些提示先不用处理，等实现了自定义快捷键功能之后再处理。
