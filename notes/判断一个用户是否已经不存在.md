# 判断一个用户是否已经不存在

在使用一些需要传递用户 ID 的 API 时，如果这个用户的账号已经不存在，API 可能会产生错误。

但有时同一个错误代码可能有多种原因，不一定是用户 ID 不存在了，此时就需要实际检查这个用户是否已经不存在了，以确定真实原因。

例如：在添加一个关注的用户时（`https://www.pixiv.net/bookmark_add.php`），目前已知有两种情况都会产生 403 错误：
1. 当前登录的用户已经被封禁，没有权限关注用户
2. 当前登录的用户有权限关注用户，但是要关注的这个用户 ID 已经不存在了。

## 通过 API 判断

可以获取指定用户的粗略数据来判断它是否存在。

正常的用户会返回 `200` 状态码，例如：

https://www.pixiv.net/ajax/user/13766727?full=0&lang=zh

不存在的用户会返回 `404` 状态码，例如：

https://www.pixiv.net/ajax/user/3809548?full=0&lang=zh

另外，也可以进一步判断返回数据的 `error` 属性：正常用户的 `error` 属性是 `false`，不存在的用户的 `error` 为 `true`。

正常用户的数据示例：

```json
{
  "error": false,
  "message": "",
  "body": {
    "userId": "13766727",
    "name": "梅鮭たかな",
    "image": "https://i.pximg.net/user-profile/img/2021/05/31/11/41/50/20794696_95126fded10d4260feaa86319152bbd4_50.png",
    "imageBig": "https://i.pximg.net/user-profile/img/2021/05/31/11/41/50/20794696_95126fded10d4260feaa86319152bbd4_170.png",
    "premium": false,
    "isFollowed": true,
    "isMypixiv": false,
    "isBlocking": false,
    "background": null,
    "sketchLiveId": null,
    "partial": 0,
    "sketchLives": [],
    "commission": null
  }
}
```

不存在的用户的数据示例：

```json
{
  "error": true,
  "message": "抱歉，您当前所寻找的个用户已经离开了pixiv, 或者这ID不存在。",
  "body": []
}
```
