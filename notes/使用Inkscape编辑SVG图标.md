# 使用 Inkscape 编辑 SVG 图标

> 本项目的图标源文件位于 `src/static/icons/*.svg`。单个文件通常是单个 `<path>`,`viewBox="0 0 1024 1024"`,并带有 Inkscape 的命名空间(可直接用 Inkscape 打开编辑)。
>
> **改完图标后必须重新生成精灵图**:执行 `npm run gen:icons`。该脚本会读取 `src/static/icons/` 下所有 svg,同时覆盖写入 `src/static/lib/icon-sprite.js` 和 `dist/lib/icon-sprite.js` —— **两个产物都要提交 git**。

## 调整图标粗细

先分清要改的图标属于哪种形状,加粗方法完全不同:

- **线条风格图标**(如 `home-line`):路径是描边(`fill: none` + `stroke: …`),加粗 = 加大描边宽度;
- **填充风格图标**(如 `home-fill`):路径整体填充、没有描边,加粗 = 让轮廓向外偏移一圈(视觉上变粗)。

### 填充形状:用「动态偏移」加粗

1. 用选择工具选中填充路径;
2. 菜单 **路径 → 动态偏移**(Path → Dynamic Offset,快捷键 `Ctrl+J`);
3. 切换到节点工具(F2),图形上会出现一个**菱形控制柄**,向外拖一小段距离即可加粗;
   - 数值参考:1024 坐标系下,拖 10~40 通常是"略微加粗"的合适幅度;
4. 满意后如需把偏移结果固化成一个普通路径(摆脱对控制柄的依赖),再执行 **路径 → 对象转路径**(Path → Object to Path,`Ctrl+Shift+C`),并删除原来的路径。

陷阱:动态偏移对**尖角、凹陷细节较多的复杂轮廓**,偏移量稍大时可能产生自交、毛刺,或把尖角变圆。出现变形时:撤销操作、减小偏移量,或在偏移后切到节点工具手动微调出问题的节点。

### 线条形状:调大描边宽度

1. 选中路径;
2. 打开 **填充与描边** 面板(快捷键 `Shift+Ctrl+F`),切到「描边样式」标签;
3. 增大**宽度**数值。1024 坐标系下图标常见笔画宽度约 60~100,建议每次增加 10~20 再观察;
4. 如果图形是封闭描边,加粗后尖角可能会"扎出来",可在同一面板把「转角」设为圆角(`round`)。

### 注意事项

- 填充类图标文件里**不要残留描边**,否则精灵图会原样带进去,出现描边叠在填充上的效果;
- 「把整个图标横向拉宽」(不等比拉伸,如想让它变矮胖)不属于加粗,应使用 **变换 → 缩放** 单独调整 X 方向。符号类图标一般不推荐拉伸,容易失真;
- 保存 svg 后记得执行 `npm run gen:icons`,并在页面里核对实际渲染效果,最后把源 svg 与两个 `icon-sprite.js` 一起提交。
