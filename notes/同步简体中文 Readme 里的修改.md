# 同步简体中文 Readme 里的修改

下载器的根目录有多个 Readme 文档：
- README.md
- README-EN.md
- README-JA.md
- README-KO.md
- README-RU.md
- README-ZH-CN.md

每个 md 文件都使用不同的语言，在文件名的后缀里有各自的语言标志。其中，没有语言标记的默认 `README.md` 是英文，它和 `README-EN.md` 的内容应当保持相同。

当我修改 Readme 时，通常会先修改 `README-ZH-CN.md`，然后把修改的内容同步到其他语言的 Readme 文档里（并且需要翻译为对应语言）。
