# 小说分类页面里的所有分类

## 该页面的介绍

小说分类页面按年龄限制可以分为全年龄版和 R-18 版：

- https://www.pixiv.net/genre/novel
- https://www.pixiv.net/genre/novel/male?mode=r18

在页面顶部可以看到一些分类，每种分类都有 id 属性，值是字符串形式的数字。

大部分分类在两种页面里都存在，但也有少部分分类只存在于某一种页面里。具体来说：
- 只存在于全年龄版的分类有：综合、儿童向
- 只存在于 R-18 版的分类有：受男性欢迎、受女性欢迎

备注：
- 小说分类页面里的所有小说都是原创小说，因为只有原创小说可以选择分类。
- 小说分类页面里的 3 个 id 0，是从所有原创作品里汇总而来的 3 个分类页面，并不是真的有一个具体分类的 id 是 0。

## 小说里的 genre 是怎么来的

用户在投稿小说时，如果选择了“原创作品”标记，那么就会出现一个“分类”下拉框，里面有多种分类。

每种分类都对应着分类页面里的某个分类（但不包含 id 为 0 的三个分类），其 id 就是 genre 属性的值。

PS：下拉框里的“其他”分类对应的 id 是 17，不是 0。

原创作品必须选择一个分类，否则无法投稿。因此原创作品的 genre 属性通常不会是 "0"。

除非一个原创作品没有选择分类，它的 genre 属性才可能是 "0"。确实有这种情况，例如：

https://www.pixiv.net/novel/show.php?id=29312531

但我不知道他是如何做到不选择分类的。

所以：
- 原创、非原创作品的 genre 属性都可能是 "0"。
- genre 为 "0" 时，说明这个小说不是原创作品；或者它是原创作品，但没有选择分类。

## 小说里 genre 属性的作用

小说的详细数据里有 genre 属性，值是对应的分类 id（字符串数字，如 "0"、"1"、"2" 等）。

如果 id 不为 0，那么在小说详情页面（及某些缩略图里），会显示对应分类的标记。

例如，下面这篇小说的 genre 是 "10"，所以在它的详情页面里，标签列表左侧会显示“BL”标记：

https://www.pixiv.net/novel/show.php?id=18762548

注意：这个“BL”不是小说的标签，而是对应分类的标记。

由于这篇小说本身没有 BL 标签，所以即使用户在下载器的“标签不能含有”里设置了 BL，下载器也无法排除这篇小说。

为了应对这种情况，我在这里保存了小说分类的对应关系，用来辅助下载器检查小说的标签。

## 作品页面里根据作品属性显示的标记

PS：即使作品的标签列表里没有某些标签，Pixiv 也会根据作品的属性显示一些标记，例如：
- R-18 作品会显示 R-18 标记
- AI 生成的作品会显示“AI生成”标记
- 原创作品会显示“原创”标记
- 对应分类的作品会显示分类标记
