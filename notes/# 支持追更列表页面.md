# 支持追更列表的小说分类页面

我想让你帮我支持在“追更列表的小说分类页面”里抓取。
需要你使用 CDP 来远程调试 Chrome 浏览器，自助完成需要的工作。
你应该使用副屏上的 Chrome 浏览器，并且遵守 agents.md 里的 CDP 调试指南。

该页面的网址：
https://www.pixiv.net/following/watchlist/novels
里面的作品全都是系列作品，没有单篇作品。
该页面有页码，一页最多 24 个系列小说。

API 是：
https://www.pixiv.net/ajax/watch_list/novel?p=1&new=1&lang=zh
其中 p 是页码数字， `new=1` 是固定的。
你需要获取该 API 返回的数据，为其生成类型描述，保存到 src/ts/crawl/CrawlResult.d.ts 里的类型 WatchListNovelData 里。现在它是空对象，只是个占位符。生成类型描述时不要拆分成多个模块，保持在这一个类型里。

然后完善 src/ts/crawlMixedPage/InitWatchListNovelPage.ts，在里面补全“保存本页面的系列 id 列表”的代码。

还需要为 `_抓取追更列表` 添加 i18n 翻译。
