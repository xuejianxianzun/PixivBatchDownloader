在漫画、小说的追更列表里，目前使用的 API 是 PC 端的（一页返回 24 条系列数据）。
在移动端里，使用的 API 与 PC 端不同：网址和参数不同；每页返回的系列数量也不同（最多 10 个）。
这两个模块目前只支持 PC 端，并没有对移动端的 API 进行适配。
现在进行适配。

需要修改的地方主要是：
- 使用 Config.mobile 判断是不是移动端。
- 在 `_抓取x页_每页最多含有x个作品` 时，PC 端显示 24，移动端显示 10。
- 使用移动端的 API，修改获取系列 id 的步骤。

移动端小说追更列表的 API：
https://www.pixiv.net/touch/ajax/watch_list/novel?p=1&limit=10&new=1&lang=zh
只需要设置参数 p，其他参数使用固定的即可。
需要在 API.ts 模块里，为这个 API 添加方法；在 src/ts/crawl/CrawlResult.d.ts 里声明类型。对于其 ads 属性，声明为 {} 即可，不需要对里面的数据声明类型，因为没必要。
提取数据时，从 body.novelSeries 里获取系列小说的数据。
body.maxPage 是最大页数。

移动端漫画追更列表的 API：
https://www.pixiv.net/touch/ajax/watch_list/manga?p=1&limit=10&lang=zh
只需要设置参数 p，其他参数使用固定的即可。
需要在 API.ts 模块里，为这个 API 添加方法；在 src/ts/crawl/CrawlResult.d.ts 里声明类型。对于其 ads 属性，声明为 {} 即可，不需要对里面的数据声明类型，因为没必要。
提取数据时，从 body.illustSeries 里获取系列小说的数据。
body.maxPage 是最大页数。
